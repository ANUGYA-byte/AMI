# 📱 AMI — Technovation Mobile Application

## 📌 About the Project

**AMI** is an Android mobile application created as part of the **Technovation** project. The application was developed using **MIT App Inventor**, providing a visual and beginner-friendly approach to mobile application development.

## 🚀 Getting Started

### Option 1 — Open the project in MIT App Inventor

1. Open **MIT App Inventor**.
2. Sign in to your account.
3. Import the `.aia` project file.
4. Open the project.
5. Modify or continue developing the application.

### Option 2 — Install the APK

The `.apk` file is the compiled Android version of the application.

Download the APK from the repository and install it on a compatible Android device.

> **Note:** Android may display a security warning when installing an APK downloaded outside the Play Store.
